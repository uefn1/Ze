ターミナルで過ごす時間が長い開発者にとって、小さなCLIツールの改善は日々の生産性に直結します。本記事では、導入が簡単で効果を実感しやすいCLIツールを7つ紹介します。

## 選定のポイント

今回の選定では次の観点を重視しました。

- インストール後すぐに使える
- 既存のシェルやGitワークフローを壊さない
- 学習コストが低く、チームへ共有しやすい
- 特定のクラウドやサービスへ依存しない

いずれも小さく試せるツールなので、気になったものから1つずつ導入するのがおすすめです。

## 1. ripgrep — 高速なコード検索

ripgrep（`rg`）はRust製の検索ツールです。`.gitignore`を尊重して検索対象を絞り込み、大規模なリポジトリでも高速に動作します。

```bash
rg "TODO" src/
rg -t ts "useEffect"
```

`grep`の置き換えとして使いやすく、エディタやCIから呼び出す場面でも安定しています。

## 2. fd — 直感的なファイル検索

fdは`find`の代替として使えるファイル検索ツールです。デフォルトで隠しファイルや`.gitignore`対象を除外し、色付きの結果を返します。

```bash
fd config
fd -e md -x wc -l
```

正規表現やオプション名が覚えやすく、ちょっとしたファイル探索のストレスを減らせます。

## 3. bat — シンタックスハイライト付きのcat

batは`cat`を置き換えるビューアです。行番号、シンタックスハイライト、Gitの差分表示を備えています。

```bash
bat src/main.ts
bat --diff README.md
```

ページャとも連携できるため、長いログや設定ファイルを読むときに便利です。

## 4. delta — Gitの差分を見やすくする

deltaは`git diff`の表示を改善するツールです。行内の差分を強調し、サイドバイサイド表示にも対応します。

```bash
git config --global core.pager "delta"
```

設定は数行で済み、既存のGit操作を変えずにレビュー体験だけを向上できます。

## 5. zoxide — 賢くディレクトリを移動する

zoxideは使用頻度を学習してディレクトリ移動を補助するツールです。`cd`の代替として使えます。

```bash
z proj
zi
```

よく移動するディレクトリほど短い入力で到達できるため、深い階層を持つモノレポで効果を発揮します。

## 6. direnv — ディレクトリごとに環境変数を切り替える

direnvはカレントディレクトリの`.envrc`を読み込み、環境変数を自動で切り替えます。

```bash
echo 'export API_URL=http://localhost:3000' > .envrc
direnv allow
```

プロジェクトごとに異なる接続先や認証情報を扱う場面で、手動の`export`から解放されます。`.envrc`には秘密情報を直接書かず、必要に応じてシークレット管理と組み合わせましょう。

## 7. gh — GitHubをターミナルから操作する

GitHub CLI（`gh`）は、IssueやPull Requestの操作をターミナルから行えるツールです。

```bash
gh pr create --fill
gh pr checks --watch
```

ブラウザとターミナルを行き来する回数が減り、CIの確認まで一連の流れで完結します。

## まとめ

今回紹介したツールは、いずれも既存のワークフローへ小さく足せるものばかりです。まずは`ripgrep`と`fd`のような検索系から試し、慣れてきたら`delta`や`direnv`へ広げると定着しやすくなります。

ツールを入れること自体が目的にならないよう、日々の待ち時間や手作業を減らすために取捨選択していきましょう。
