## はじめに

開発を始めるとき、コードを書く時間より環境構築に時間を取られていませんか？

Pythonの仮想環境、Node.jsのバージョン、LinterとFormatterの設定……。プロジェクトごとに微妙に異なる手順を踏むのは、地味に大きな負担です。

この記事では、そんな環境構築を軽くするツールとして **uv**、**Biome**、**mise** の3つを紹介します。どれも「設定を減らす」「動作を速くする」という方向性で、日々の開発体験を改善してくれます。

## uv：Pythonの环境構築をひとつにまとめる

uvはRust製のPythonパッケージマネージャーです。pipやvenv、pyenv、pip-toolsが担っていた役割を、ひとつのコマンドにまとめてくれます。

### インストール

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### プロジェクトを作る

```bash
uv init myapp
cd myapp
uv add fastapi
uv run python main.py
```

`uv add` は依存関係の追加とロックファイルの更新を同時に行い、`uv run` は仮想環境を意識せずにコマンドを実行できます。

### Python本体のバージョンも管理できる

```bash
uv python install 3.12
uv python pin 3.12
```

プロジェクトごとにPythonのバージョンを固定できるため、チーム内での「私の環境では動く」問題を減らせます。

### CIではロックファイルを固定する

```bash
uv sync --frozen
```

CIでは `--frozen` を付けることで、ロックファイル通りに依存関係を再現できます。

## Biome：LinterとFormatterを1ツールに

BiomeはJavaScript/TypeScript向けのLinter兼Formatterです。ESLintとPrettierを別々に設定する代わりに、ひとつのツールとひとつの設定ファイルで済みます。

### 導入

```bash
npm i -D --save-exact @biomejs/biome
npx biome init
```

### チェックと自動修正

```bash
npx biome check .
npx biome check --write .
```

`biome.json` では、インデントやLintルールをまとめて管理できます。

```json
{
  "formatter": {
    "indentStyle": "space",
    "indentWidth": 2
  },
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true
    }
  }
}
```

設定ファイルが少ないことは、それだけで保守コストの削減になります。

## mise：複数言語のバージョンを一元管理

miseはPython、Node.js、Ruby、Goなどのバージョンをまとめて管理できるツールです。

```bash
mise use --global python@3.12 node@22
mise install
```

プロジェクト直下に `.mise.toml` を置けば、ディレクトリに入るだけで必要なバージョンへ切り替わります。

```toml
[tools]
python = "3.12"
node = "22"
```

言語ごとにバージョン管理ツールを入れ替える必要がなくなるのが大きなメリットです。

## 3ツールの役割分担

| ツール | 役割 | うれしい点 |
| --- | --- | --- |
| uv | Pythonの依存関係と仮想環境 | 高速でコマンドが少ない |
| Biome | JS/TSのLintとFormat | 設定ファイルを統一できる |
| mise | 言語ランタイムのバージョン管理 | 複数言語を一元管理できる |

## 小さく始めるなら

まずは次の順番で試すのがおすすめです。

1. Pythonプロジェクトなら `uv init` から始める
2. JS/TSプロジェクトに `biome init` を追加する
3. 言語をまたぐプロジェクトで `mise` を導入する

すべてを一度に置き換える必要はありません。ひとつずつ試して、手に合うものから定着させていきましょう。

## まとめ

- **uv** でPythonの環境構築を高速化する
- **Biome** でLinterとFormatterの設定を統一する
- **mise** で言語バージョンの管理を一本化する

環境構築の手順が減ると、本質的な開発に使える時間が増えます。まだ使っていないツールがあれば、小さなプロジェクトから試してみてください。
