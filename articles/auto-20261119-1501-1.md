## はじめに

Pythonの開発環境構築といえば、これまで `pip`・`venv`・`pyenv`・`pip-tools` などを組み合わせるのが一般的でした。便利な反面、ツールごとにコマンドや設定ファイルが異なり、初期構築やCIの再現性で悩んだ経験のある方も多いはずです。

そこで注目したいのが、Astralが開発する **uv** です。Rust製の高速なパッケージマネージャーでありながら、Python本体のバージョン管理、仮想環境、依存関係のロック、スクリプト実行までを一貫して扱えます。本記事では、uvの基本操作を実際のコマンドとともに紹介します。

## uvとは

uvは「Python向けの高速なパッケージ・プロジェクトマネージャー」です。主な特徴は次のとおりです。

- `pip` 互換の高速な依存解決・インストール
- `pyproject.toml` と `uv.lock` による再現性のある依存管理
- Pythonインタプリタのバージョン管理
- `venv` に代わる仮想環境の自動作成
- 単一ファイルスクリプトの依存関係をインラインで記述して実行

複数のツールを覚える必要が減り、ローカルとCIで同じコマンドを使いやすくなる点が大きな魅力です。

## インストール

macOS・Linuxでは公式スクリプトで導入できます。

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Homebrewを使う場合は次のとおりです。

```bash
brew install uv
```

インストール後、バージョンを確認します。

```bash
uv --version
```

## プロジェクトを作成する

新しいプロジェクトは `uv init` で作成できます。

```bash
uv init myapp
cd myapp
```

生成される `pyproject.toml` にプロジェクト情報がまとまります。アプリケーション用の構成にしたい場合は `--app`、ライブラリ用なら `--lib` を指定すると雛形が変わります。

```bash
uv init --app myapp
```

## 依存関係を追加・同期する

パッケージの追加は `uv add` です。

```bash
uv add requests
```

開発用の依存関係は `--dev` を付けます。

```bash
uv add --dev pytest ruff
```

`uv add` を実行すると、`pyproject.toml` の更新、`uv.lock` の生成、仮想環境へのインストールまでが自動で行われます。既存プロジェクトをクローンした場合は、ロックファイルから環境を再現できます。

```bash
uv sync
```

CIでは `uv sync --frozen` を使うと、ロックファイルを変更せずに依存関係をインストールできます。

```bash
uv sync --frozen
```

## Pythonのバージョンを管理する

uvはPython本体のインストールも行えます。

```bash
uv python install 3.12
```

プロジェクトで使うバージョンを固定する場合は、`pyproject.toml` の `requires-python` を設定し、必要に応じて `.python-version` を用意します。

```bash
uv python pin 3.12
```

これにより、チーム内やCIで利用するPythonバージョンのずれを抑えられます。

## スクリプトを手軽に実行する

uvの便利な機能のひとつが、PEP 723形式のインラインスクリプトメタデータです。ファイル内に依存関係を書いておけば、事前に仮想環境を作らなくても実行できます。

```python
# /// script
# requires-python = ">=3.12"
# dependencies = [
#     "httpx",
# ]
# ///

import httpx

response = httpx.get("https://example.com")
print(response.status_code)
```

実行は `uv run` だけです。

```bash
uv run script.py
```

ちょっとした自動化スクリプトや検証コードを書くときに非常に便利です。

## ツールを一時実行する

`uvx` を使うと、グローバル環境を汚さずにCLIツールを実行できます。

```bash
uvx ruff check .
uvx black --check .
```

「このコマンドだけ試したい」という場面で重宝します。

## CIで活用する

GitHub Actionsでは `astral-sh/setup-uv` を利用すると導入が簡単です。

```yaml
- uses: astral-sh/setup-uv@v5
  with:
    python-version: "3.12"

- run: uv sync --frozen
- run: uv run pytest
```

ローカルと同じ `uv sync` / `uv run` を使えるため、CI固有の手順を減らせます。

## まとめ

uvは、Python開発における環境構築と依存管理をひとつにまとめてくれるツールです。高速なインストールに加え、ロックファイルによる再現性、Pythonバージョン管理、スクリプト実行までカバーしており、新規プロジェクトでも既存プロジェクトでも導入しやすいのが特徴です。

まずは `uv init` と `uv add` から試し、徐々に `uv run` や `uvx` に広げていくのがおすすめです。pip中心のワークフローから一歩進めたい方は、ぜひ一度触ってみてください。
