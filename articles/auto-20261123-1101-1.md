## はじめに

Pythonの依存関係管理は、長らく「遅い・複雑・ツールが乱立」という課題を抱えてきました。`pip`、`virtualenv`、`pip-tools`、`Poetry`、`pyenv`……目的ごとに別々のツールを組み合わせる必要があり、初学者にも経験者にも負担が大きい領域です。

そんな状況を一変させているのが、Astral社が開発する **uv** です。Rustで書かれた超高速なPythonパッケージマネージャで、依存解決・仮想環境・Python本体のバージョン管理までを1つのCLIに統合しています。本記事では、uvの特徴と実践的な使い方をまとめます。


## uvとは

uvは「Python向けのCargo」を目指して開発されているツールです。主な特徴は次の通りです。

- **圧倒的な速度**: Rust製で、`pip` や `Poetry` と比較して依存解決・インストールが大幅に高速
- **オールインワン**: パッケージ管理、仮想環境、ロックファイル、Pythonバージョン管理を統合
- **pip互換インターフェース**: 既存の `pip` コマンドをほぼそのまま置き換え可能
- **ロックファイルによる再現性**: `uv.lock` で環境を固定し、チーム開発でも同一構成を再現
- **ツール実行**: `uvx` でインストール不要のワンショット実行が可能

## インストール

macOSやLinuxでは公式インストーラが利用できます。

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Homebrewを使う場合は次の通りです。

```bash
brew install uv
```

インストール後、バージョンを確認します。

```bash
uv --version
```

## プロジェクトを作ってみる

uvは `init` コマンドでプロジェクトの雛形を生成できます。

```bash
uv init my-app
cd my-app
```

これだけで `pyproject.toml` と `.python-version` が作成され、プロジェクト管理の準備が整います。

依存パッケージの追加は `add` コマンドで行います。

```bash
uv add requests
uv add --dev pytest ruff
```

`pyproject.toml` に依存が追記され、同時に `uv.lock` が生成・更新されます。仮想環境の作成もuvが自動で行うため、`python -m venv` を手動で叩く必要はありません。

## 依存関係の同期と実行

ロックファイルに基づいて環境を同期するには `sync` を使います。

```bash
uv sync
```

スクリプトの実行は `run` 経由で行うと、プロジェクトの仮想環境が自動で使われます。

```bash
uv run python main.py
uv run pytest
```

CI環境では `uv sync --frozen` を使うことで、ロックファイルを変更せずに厳密に同期できます。

```bash
uv sync --frozen
```

## pipからの移行

既存プロジェクトで `pip` を使っている場合も、uvのpip互換コマンドで段階的に移行できます。

```bash
# 従来の pip install の代わり
uv pip install requests

# requirements.txt からの一括インストール
uv pip install -r requirements.txt

# 現在の環境をrequirements.txtへ出力
uv pip freeze > requirements.txt
```

まずは `pip` の置き換えから始め、慣れてきたら `pyproject.toml` + `uv.lock` によるプロジェクト管理へ移行するのがおすすめです。

## Python本体のバージョン管理

uvはPythonインタプリタのインストールと切り替えも担います。

```bash
# 利用可能なバージョンの一覧
uv python list

# 特定バージョンをインストール
uv python install 3.12

# プロジェクトで使うバージョンを固定
uv python pin 3.12
```

`pyenv` を別途用意する必要がなくなるため、環境構築の手順を大きく削減できます。

## uvxでツールを即実行

`uvx`（`uv tool run` のエイリアス）を使うと、グローバル環境を汚さずにCLIツールを実行できます。

```bash
uvx ruff check .
uvx black .
```

常時使うツールは `uv tool install` で管理できます。

```bash
uv tool install ruff
```

## まとめ

uvは「速い」だけでなく、Python開発の環境構築にまつわる複数のツールを1つにまとめてくれる点が本質的な魅力です。

- 依存管理・仮想環境・Pythonバージョン管理を統一
- `uv.lock` による再現性の高い環境構築
- pip互換コマンドで段階的な移行が可能
- `uvx` による手軽なツール実行

まずは小さなプロジェクトで `uv init` から試し、効果を実感してみてください。一度体験すると、従来のワークフローには戻れなくなるはずです。
